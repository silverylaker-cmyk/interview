# 이비인후과 문진

이비인후과 의원에 온 환자가 태블릿이나 휴대폰으로 직접 작성하는 문진 웹앱입니다.
환자는 평소 쓰는 한글 표현으로 증상을 고르고, 작성이 끝나면 의료진에게 **영어 의학용어로 정리된 요약**을 보여 줍니다.

- 서버 없이 동작하는 정적 웹앱입니다. `index.html` 을 브라우저로 열면 바로 쓸 수 있습니다.
- 입력 내용은 화면에만 표시되고 저장 · 전송되지 않습니다. 「새 환자 시작」을 누르면 지워집니다.

## 화면 흐름

1. **불편한 곳** — 귀, 코, 목 안, 목소리, 기침 · 숨, 입, 어지럼, 얼굴 · 턱, 목 겉, 코골이 · 잠, 전신, 아이, 검사 · 상담
2. **증상 고르기** — 부위마다 환자 말투로 쓴 증상 목록 (예: "귀가 먹먹해요 · 막힌 느낌이에요")
3. **자세히** — 어느 쪽, 언제부터, 얼마나, 증상별 추가 질문 (이명 소리 종류, 콧물 색, 어지럼 지속 시간 등)
4. **건강 정보** — 앓는 병, 먹는 약, 알레르기, 수술, 최근 있었던 일, 흡연 · 음주
5. **확인** → **의료진용 요약 (영어)** — Alerts, CC, HPI, History. 「Copy as text」로 차트에 붙여 넣거나 인쇄

## 환자가 증상을 못 고르는 일이 없도록

- 증상 사전 206개. 환자 표현은 진료 상담 글 · 병원 건강정보 · 기사에서 실제로 쓰이는 말을 모아 정리했습니다.
- 모든 부위와 첫 화면에 **직접 쓰기** 칸이 있습니다. 쓰는 동안 "혹시 이 증상인가요?" 후보를 보여 주고,
  맞는 것이 없으면 **적은 그대로 전달하기**를 누르면 됩니다.
- 직접 쓴 말은 번역하지 않고 원문 그대로 의료진 화면에 나옵니다. 사전이 찾아낸 용어가 있으면
  `Keyword match (unconfirmed)` 로 함께 표시합니다. 자동 번역이 아니라 낱말 대조이므로 참고용입니다.
- "약 타러 왔어요", "진단서가 필요해요" 같은 증상이 아닌 용무도 고를 수 있습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `data.js` | 증상 사전 (한글 표현 → 영어 용어, 검색어, 주의 문구), 추가 질문, 과거력 문항 |
| `matcher.js` | 환자가 쓴 말에서 증상을 찾는 검색기 |
| `app.js` · `styles.css` · `index.html` | 화면 |
| `tests/matcher.test.js` | 환자 표현 144개가 맞는 증상으로 찾아지는지 점검 |
| `scripts/build-single.js` | CSS · JS 를 한 파일에 넣은 `dist/index.html` 생성 |

```bash
npm test          # 사전 · 검색기 점검
npm run build     # dist/index.html (파일 하나로 배포할 때)
```

## 증상 추가 · 수정

`data.js` 의 `S` 배열에 한 줄을 추가합니다.

```js
["ear_fullness", "ear", "먹먹함", "귀가 먹먹해요 · 막힌 느낌이에요", "Aural fullness",
  ["먹먹|멍멍|벙벙", "$귀+$막힘"], { lat: 1 }],
// id, 부위, 묶음, 환자에게 보이는 말, 의사에게 보이는 용어, 검색어, 옵션
```

- 검색어에서 `|` 는 "이 중 하나", `+` 는 "모두 있어야 함" 입니다. `$아픔` `$부음` 같은 매크로는 활용형 묶음입니다.
- 옵션: `lat` 좌우를 묻기, `flag` 의료진 화면 Alerts 에 띄울 문구, `q` 추가 질문 묶음.
- 고친 뒤 `tests/matcher.test.js` 에 환자 표현을 한 줄 더하고 `npm test` 로 확인하세요.

## 알아 둘 점

- 의료진 화면의 Alerts 는 선택한 증상 · 기간 · 복용 약을 조합한 **참고용 알림**이며 진단이 아닙니다.
  영어 용어와 알림 기준은 진료에 쓰기 전에 원장님이 한 번 검토해 주세요.
- 결과를 다른 기기 (진료실 PC, EMR)로 보내는 기능은 없습니다. 지금은 화면을 보여 주거나, 텍스트 복사 · 인쇄로 전달합니다.
